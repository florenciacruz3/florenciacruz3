## 1. Project Summary

This project contains the details of what this internship entails, what is expected of me, and how can I excel in this business. 


---

## 2. Business Need

This project is done to serve as a point of connection between Erik and his client. What is needed from my part is to be attentive, and consistent with my work in order to be able to set up calls for him with prospect clients. 

---

## 3. Project Goals

- Land 4 calls out of 100 emails sent
- Send 20 emails a day
- Keep up with follow-ups

---

## 4. Scope

### In Scope

- Learn how to navigate HubSpot efficiently
- Be detail oriented - one mistake on an email massage can turn the situation from prospective client to lost client. 
- Show up and be present in Teams meetings
- Commit to doing consistent work (20 emails a day)
- Adapt as the project changes

### Out of Scope

- Calling clients on the phone 
- Answering technical questions about what Informed Decisions does
- Contacting clients on any platform that wasn't agreed on
